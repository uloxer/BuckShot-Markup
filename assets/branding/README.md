# BuckShot Markup identity

Direction: cyan crop frame, blueprint sketch, dimensions and drafting dividers.

- `buckshot-mark.svg`: application and tray identity; render at the target size.
- `buckshot-wordmark.svg`: horizontal product lockup.
- `blueprint-panel.svg`: larger About and installer illustration.
- `toolbar/`: original 24-unit vector drawings for the editor icon provider.

Palette: ink `#10243a`, cyan `#25d9ed`, paper `#f4fbff`.
Small toolbar glyphs use a restrained ink outline and cyan accents; keep existing tool behavior and accessible names. Render vector sources for the current DPI instead of enlarging 16-pixel bitmaps.
