# BuckShot Markup 0.9.672

- Added editable .buckshot projects as the preferred Save As type; retained .greenshot opening and saving.
- Registered both project extensions with BuckShot Markup while respecting Windows UserChoice and restoring previous Classes associations on uninstall.
- New settings default to Ctrl+Shift+S region capture, Ctrl+Shift+C opening from clipboard, Save As dialog plus clipboard output, opaque white dimension backgrounds and one decimal place.
- Editor Save As and Copy Image shortcuts use Ctrl+Alt+S/C to avoid the new global hotkeys. Existing user settings and saved project overrides remain unchanged and all defaults remain configurable in Options.
- Improved measurement-panel row heights, wrapped labels and precision-control sizing for larger fonts/icons, with horizontal scrolling when required.

EXE installer and SHA-256 checksum only; no MSIX. Windows may retain a previously selected default application; Explorer UserChoice is not modified.
